# Deep Learning for Computer Vision — labs

Lab notebooks, datasets and tools of the course *Deep Learning for Computer Vision* (ECAM Brussels, 2026–2027): from the pixel to the motion of a robot arm. The notebooks contain `# TODO` cells to complete; the solutions are not published.

| Day | Folder | Notebooks |
|---|---|---|
| 1 — Classic vision | `J1_vision_classique/notebooks` | images with NumPy/OpenCV · filtering and features · camera projection · calibration and guidance of the arm |
| 2 — CNN | `J2_cnn/notebooks` | PyTorch and MLP · first CNN · improving a CNN · bug hunt, Grad-CAM and sorting with the arm |
| 3 — Beyond classification | `J3_avance/notebooks` | transfer learning · YOLO detection and segmentation · diffusion |

## Installation

Python 3.11 or later. From the folder of the day:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

The labs need OpenCV 4 (`opencv-contrib-python<5`). Days 1 and 2 run on a laptop CPU; Labs 10 and 11 are meant for Google Colab (GPU).

## Data

Most images are synthetic, generated by the scripts in `tools/`. Not included here:

* `coins.jpg`, `nemo.jpg`, `chessboard.jpg`, `document.jpg`, `cover.jpg` (Labs 2 and 3): distributed with the course, to copy into `J1_vision_classique/notebooks/data/`;
* Fashion-MNIST and the ants/bees images: downloaded automatically by the notebooks.

## Tools (`J1_vision_classique/tools`)

| Script | Use |
|---|---|
| `view_camera.py` | live image of the USB camera |
| `test_cameras.py` | which camera works, which index to use, field of view (`--show INDEX`) |
| `capture_calibration.py` | take the checkerboard views for the calibration |
| `make_checkerboard.py` | printable checkerboard (A4 PDF, true scale) |
| `make_robot_sheets.py` | printable ArUco markers and coloured shapes for the robot cell |
| `visit_markers.py` | moves the arm above the 4 markers (dry run by default) |

The `make_data.py`, `make_parts_dataset.py`, `make_robot_cell.py` and `make_yolo_dataset.py` scripts generate the datasets. `build_notebooks.py`, `build_slides.py` and `make_figures.py` are the authoring tools of the course; they need source files that are not published.

**Robot safety.** The scripts that move the Galatae Gal-e arm must only be run with the approval of the teacher, at low speed, with a hand near the emergency stop. The Python API of the arm (`robot.py`, GPL-3.0) is available at https://github.com/galatae-engineering/galatae-api and is not included here.
